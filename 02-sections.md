# Kitrise sections

Kitrise by digimaps.co has 31 sections that can be added from the theme editor. Entries are in alphabetical order by name. Most sections also have a color palette setting, and many have spacing settings. These are not repeated unless they matter.

## Announcement bar

A thin message bar with a short line of text, an optional link and icon.

- Templates: Header and footer section groups only.
- Blocks: Message (up to 3)
- Key settings: Color palette, Show on mobile

## Apps

A place to add Shopify app blocks anywhere on a page.

- Templates: Any template and any section group.
- Blocks: App blocks
- Key settings: Color palette

## Blog posts

A grid or swipe row of recent articles from one blog.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Blog, Number to show, Columns on desktop, Card style

## Campaign showcase

A campaign intro with a large image panel and a product list beside it.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Product (up to 4)
- Key settings: Layout, Button link, Sale badge style, Show compare-at price

## Collection cards

A set of collection cards chosen by the merchant.

- Templates: Any template and any section group.
- Blocks: Collection (up to 16)
- Key settings: Layout, Columns on desktop, Card style, Show product count

Each card can link to a collection or to a custom link, so this section also covers a grid of category cards.

## Collection page

The main product grid of the collection template, with filters, sorting and optional banner blocks.

- Templates: Only on the collection template.
- Blocks: Collection banner, Custom Liquid (1), up to 6 in total
- Key settings: Filter layout, Desktop columns, Products per page, Show filters

The page also shows the collection title. Show image and Show description control the collection image and description. A Collection banner block adds a promo banner inside the grid.

## Collection tabs

Product grids with tabs, one tab per collection or hand-picked product list.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Collection tab (up to 6)
- Key settings: Style, Products per tab, Desktop layout, Show quick view

## Contact form

A contact form with optional phone, topic and order number fields.

- Templates: Any template and any section group.
- Blocks: None.
- Key settings: Layout, Show phone field, Show inquiry topic, Show optional order number

## Countdown timer

A countdown to a launch date, with an optional product, image and a message for when it ends.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Launch date, Time zone, When it ends, Style

## Custom Liquid

A free area for custom Liquid, HTML and CSS code.

- Templates: Any template and any section group.
- Blocks: None.
- Key settings: Liquid code, Color palette

## Custom section

A flexible section with a background image that holds theme blocks (Text and Layout group).

- Templates: Any template and any section group.
- Blocks: Theme blocks (Text, Layout group)
- Key settings: Background image

## Email signup

An email signup form with optional image and consent text.

- Templates: Any template and any section group.
- Blocks: Custom Liquid (1)
- Key settings: Layout, Image, Consent and privacy text, Color palette

## FAQ

Frequently asked questions as an accordion.

- Templates: Any template and any section group.
- Blocks: Question (up to 16)
- Key settings: Layout, Open first answer, Link label, Color palette

## Featured product

One product shown with its gallery and buy box, placed on any page.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: App blocks, Product heading, Price, Product options and purchase, Product features, Complete the kit, Description, Text note, Collapsible information, Custom Liquid
- Key settings: Product, Gallery position, Desktop gallery, Keep details visible while scrolling

## Featured products

A grid of products from a collection or a hand-picked list, with an optional feature image.

- Templates: Any template and any section group.
- Blocks: None.
- Key settings: Collection, Hand-pick products, Maximum number, Card style

For a product row from one collection, pick it in Collection and set Layout to Horizontal carousel or Grid.

## Hero

A large banner with image or video, heading, text and up to two buttons.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Media type, Layout, Desktop media height, Use as the page main heading

## Hotspots

An image with clickable pins that open details or a product.

- Templates: Any template and any section group.
- Blocks: Detail (up to 5)
- Key settings: Image, Featured product, Animate pins, Open the first detail on load

## Icon benefits

A short row of icon benefits, such as shipping, returns or support.

- Templates: Any template and any section group.
- Blocks: Benefit (up to 5)
- Key settings: Layout, Heading, Color palette

## Image comparison

A before and after image slider with a draggable handle.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Before, After, Initial reveal position, Show handle instructions

## Jersey customizer

A personalizer for sports jerseys: name, number or player, print color and live preview.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Jersey model (up to 15), Print color (up to 8), Player (up to 20), App blocks, Custom Liquid, up to 50 in total
- Key settings: Printing pricing, Use name only, Use name and number, Use player selection

## Kit builder

Lets shoppers pick a set number of products and add them to the cart together.

- Templates: Any template and any section group.
- Blocks: Product (up to 8)
- Key settings: Products to choose, Offer note, Product card layout, Desktop product columns

## Lifestyle showcase

A lifestyle image with up to three product moments.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Product moment (up to 3)
- Key settings: Image, Background shade, Mobile layout, Use custom image focus

## Logo list

A row of logos, as a grid or a carousel.

- Templates: Any template. Not available in the header section group.
- Blocks: Logo (up to 12)
- Key settings: Layout, Mobile layout, Mute logos until hover or focus, Show navigation arrows

## Media collections

Large media cards that link to collections.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Collection card (up to 8)
- Key settings: Desktop columns, Mobile layout, Text placement, Show product count

## Page content

Shows the content of a Shopify page.

- Templates: Any template and any section group.
- Blocks: None.
- Key settings: Page content, Show page heading, Layout, Heading size

## Product comparison

A comparison table of selected products with feature rows.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Feature row (up to 10)
- Key settings: Products, Offer a differences-only filter, Highlighted column, Show prices

## Product information

The main product template section: gallery, product info and buy box.

- Templates: Only on the product template.
- Blocks: App blocks, Product heading, Price, Vendor, SKU, Variant picker, Quantity selector, Buy buttons, Product options and purchase, Product features, Complete the kit, Description, Text note, Collapsible information, Custom Liquid
- Key settings: Gallery position, Desktop gallery, Show breadcrumb navigation, Show compact sticky cart bar

Add Collapsible information blocks for rows of details such as shipping and returns or materials and care.

## Product kit

A product kit: an image beside a short list of products.

- Templates: Any template and any section group.
- Blocks: Product (up to 4)
- Key settings: Layout, Image position, Image ratio, Note

## Related products

Product recommendations on the product page.

- Templates: Only on the product template.
- Blocks: None.
- Key settings: Heading, Maximum products, Columns on large screens

## Video

A video section with poster, optional text and button over or below it.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Desktop file, Autoplay, Show play and pause button, Desktop ratio

## Welcome popup

A welcome popup with text, image and button.

- Templates: Any template. Not available in the header section group.
- Blocks: None.
- Key settings: Show on the online store, Open trigger, Delay before opening, Show again
