# Kitrise sections

Kitrise by digimaps.co has 31 sections that can be added from the theme editor. Entries are in alphabetical order by name. Most sections also have a color palette setting, and many have spacing settings. These are not repeated unless they matter. The content of every section follows **Page width** in Theme settings > Layout.

## Announcement bar

A thin message bar with a short line of text, an optional link and icon.

- Templates: Header and footer section groups only.
- Blocks: Message (up to 3)
- Key settings: Color palette, Show on mobile

## Apps

A place to add Shopify app blocks anywhere on a page.

- Templates: Any template and any section group.
- Blocks: App blocks
- Key settings: Color palette

## Blog posts

A grid or swipe row of recent articles from one blog.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Blog, Number to show, Desktop columns, Card style

## Campaign showcase

A campaign intro with a large image panel and a product list beside it.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Product (up to 4)
- Key settings: Layout, Button link, Sale badge style, Show compare-at price

## Collection cards

A set of collection cards chosen by the merchant.

- Templates: Any template. Not available in the header section group.
- Blocks: Collection (up to 16)
- Key settings: Layout, Desktop columns, Card style, Show product count

Each card can link to a collection or to a custom link, so this section also covers a grid of category cards.

## Collection page

The main product grid of the collection template, with filters, sorting and optional banner blocks.

- Templates: Only on the collection template.
- Blocks: Collection banner, Custom Liquid (1), up to 6 in total
- Key settings: Filter layout, Desktop columns, Products per page, Show filters, Grid style

The page opens with a title band that holds the collection title, the description (**Show description**) and the product count. With **Show image** and **Show image in title band** (`header_image`, off by default) on, the collection image sits at the right of the band. The collection needs an image for it to appear.

Under the band, **Show kit type chips** (`show_type_chips`, on by default) adds quick filters by product type. They need **Show filters** on and the Product type filter active in Search & Discovery (see "Filters (Search & Discovery)" in Products, variants and metafields).

**Grid style** (`grid_style`) is **Ruled** (default, cards separated by thin lines with no gap) or **Spaced** (cards separated by a gap).

A Collection banner block adds a promo banner inside the grid.

## Collection tabs

Product grids with tabs, one tab per collection or hand-picked product list.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Collection tab (up to 6)
- Key settings: Style, Products per tab, Desktop layout, Show quick view

## Contact form

A contact form with optional phone, topic and order number fields.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Layout, Image, Show phone field, Show inquiry topic, Show optional order number

## Countdown timer

A countdown to a launch date, with an optional product, image and a message for when it ends.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Launch date, Time zone, When it ends, Style

## Custom Liquid

A free area for custom Liquid, HTML and CSS code.

- Templates: Any template and any section group.
- Blocks: None.
- Key settings: Liquid code, Color palette

## Custom section

A flexible section with a background image that holds theme blocks (Text, Button, Image and Layout group).

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Theme blocks (Text, Button, Image, Layout group)
- Key settings: Background image, Color palette, Top spacing, Bottom spacing

Color palette offers Light (default), Soft, Dark, Accent and Brand colors. **Top spacing** and **Bottom spacing** (0 to 96 px, default 40) are under the **Mobile** header. Turn on **Show advanced controls** under the **Advanced** header to set **Desktop top spacing** and **Desktop bottom spacing** (0 to 160 px, default 72).

Besides Text and the layout group, the section accepts **Button** and **Image** blocks. A Text block in the **Heading** style is read as a heading by screen readers. Button has **Label**, **Link** and **Button style** (Solid, Outline, Quiet). Image has **Image**, **Image ratio** (Natural, Square, Portrait, Landscape) and **Round corners**. The section adds a **Custom section** preset and two more presets, **Rich text** (heading, text and button) and **Image with text** (image beside text and a button).
## Email signup

An email signup form with optional image and consent text.

- Templates: Any template. Not available in the header section group.
- Blocks: Custom Liquid (1)
- Key settings: Layout, Image, Consent and privacy text, Color palette

## FAQ

Frequently asked questions as an accordion.

- Templates: Any template. Not available in the header section group.
- Blocks: Question (up to 16)
- Key settings: Layout, Open first answer, Link label, Color palette

## Featured product

One product shown with its gallery and buy box, placed on any page.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: App blocks, Product heading, Price, Product options and purchase (classic), Product features, Complete the kit, Description, Text note, Collapsible information, Custom Liquid
- Key settings: Product, Gallery position, Desktop gallery, Keep details visible while scrolling

Until a product is selected the section does not show on the storefront. The theme editor shows a placeholder with a sample price so you can place it. Under **Advanced**, **Show denomination card design** works as in the Product information section (see "Denomination card preview" in Products, variants and metafields).

## Featured products

A grid of products from a collection or a hand-picked list, with an optional feature image.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Collection, Hand-pick products, Maximum number, Card style

For a product row from one collection, pick it in Collection and set Layout to Horizontal carousel or Grid.

## Hero

A large banner with image or video, heading, text and up to two buttons.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Media type, Layout, Desktop media height, Use as the page main heading

**Use as the page main heading** is off by default. Turn it on for one section per page only.

## Hotspots

- Blocks: Detail (up to 5)
- Key settings: Image, Featured product, Animate pins, Open the first detail on load

## Icon benefits

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Benefit (up to 5)

## Image comparison

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Before, After, Initial reveal position, Show handle instructions

- Blocks: Jersey model (up to 15), Print color (up to 8), Player (up to 20), App blocks, Custom Liquid, up to 50 in total
- Key settings: Printing pricing, Use name only, Use name and number, Use player selection, Allow squad orders

## Kit builder

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Product moment (up to 3)

## Logo list

A row of logos, as a grid or a carousel.

## Media collections

- Templates: Any template. Not available in header or footer section groups.

## Page content

- Templates: Any template. Not available in header or footer section groups.
- Blocks: None.
- Key settings: Page content, Show page heading, Layout, Heading size

## Product comparison

A comparison table of selected products with feature rows.

- Templates: Any template. Not available in header or footer section groups.
- Blocks: Feature row (up to 10)
- Key settings: Products, Offer a differences-only filter, Highlighted column, Show prices

## Product information

The main product template section: gallery, product info and buy box.

- Templates: Only on the product template.
- Blocks: App blocks, Product heading, Price, Vendor, SKU, Variant picker, Quantity selector, Buy buttons, Product options and purchase (classic), Product features, Complete the kit, Description, Text note, Collapsible information, Custom Liquid
- Key settings: Gallery position, Desktop gallery, Show breadcrumb navigation, Show compact sticky cart bar

Add Collapsible information blocks for rows of details such as shipping and returns or materials and care.

A Complete the kit or Text note block that does not match the current product is not shown on the storefront. In the theme editor it shows the note "Not shown on this product" only while it is selected.

## Header, search, article and 404 sections

These four sections belong to fixed places in the theme and are not part of the count above. Open the matching page in the theme editor to change them.

### Header

Open the **Header group** and select the **Header** section.

**Two-level dropdown style** is hidden when the layout is the centered logo with drawer navigation. It chooses how a desktop menu item with one level of sub-links opens. The options are **Text list** and **Image tiles**. The default in the theme's own header group is **Image tiles**. A header that does not have the setting saved uses **Text list**. The help text reads: "Menu items with one level of sub-links. Tiles show the collection or product image next to each title. Up to 6 collection or product links show an image. Items with three levels keep the mega menu."

With **Image tiles**:

- Each sub-link that points to a collection or a product shows a tile with its image and title. The image is the collection or product image. If a collection has no image of its own, the first image of its first product is used.
- At most six tiles are shown. Further links with an image, and all links without an image (for example a page or a blog), are listed as plain text links below the tiles.
- Menu items with three levels keep the mega menu.
- The campaign tile appears beside the tiles for the menu item whose title you enter in **Navigation item for campaign**. The campaign image, text and link come from the other campaign settings in the Header section (**Campaign image**, **Campaign subheading**, **Campaign heading**, **Campaign description**, **Campaign link label**, **Campaign link**).

The page the visitor is on is marked in the menu automatically. If a top-level link points to the current page, only that link is marked. Otherwise the top-level item that contains the current page is marked. There is no setting for this.

### Search results

Select the **Search results** section on the search page. See [Filters (Search & Discovery)](04-products-variants-metafields.html#10-filters-search--discovery) for the filter drawer.

- **Quick links menu** (under the **Quick links** header) is a menu picker. The top-level links of the chosen menu, up to 8, are shown as quick links when the visitor has not searched yet and when a search has no results. Leave it empty to hide the links.

### Blog article

Select the **Blog article** section on an article page. Besides the existing date, author and tag settings it has:

- **Show share links** (on by default) shows a **Share this story** row under the article with **Copy link**, **Facebook**, **X** and **Email**. If the browser cannot copy to the clipboard, the link is shown in a text field instead.
- **Show previous and next post links** (on by default) shows **Previous story** and **Next story** links to the neighbouring articles of the same blog. The help text reads: "Links to the newer and older posts in the same blog. Works best for blogs with up to 50 posts." A link is left out when there is no story in that direction.
- **Products in this post** is a product picker (up to 4 products). The products are shown as product cards under a **Kit in this story** heading. Leave it empty to hide the list.

### 404 page

Select the **404 page** section on the 404 template. In its **Quick links** group, **Quick links menu** is a menu picker. The top-level links of the chosen menu, up to 8, appear under the search form with the label "Browse". The default is the `main-menu` menu. Leave it blank to hide the links.
